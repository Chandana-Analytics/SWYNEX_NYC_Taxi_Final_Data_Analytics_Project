# SWYNEX Technologies – Task 3

## NYC Yellow Taxi Interactive Dashboard



An interactive Power BI dashboard created as part of Task 3 of my SWYNEX Technologies Data Analytics Internship.



The dashboard presents the key findings from Task 2 in an interactive format using the cleaned January 2026 NYC Yellow Taxi dataset.



## Tool Used



- Power BI



## Dashboard KPIs



- Total Trips

- Median Trip Distance

- Median Trip Duration

- Average Total Amount



## Interactive Filters



- Date

- Weekday

- Pickup Hour

- Payment Type



## Dashboard Visuals



1. Trip Distance Distribution

2. Trips by Pickup Hour

3. Top 10 Pickup Zones

4. Trip Duration Distribution

5. Average Trips per Day by Weekday

6. Payment Type Distribution



## Objective



To transform the analysis from Task 2 into an interactive Power BI dashboard that allows users to explore key trip, time, payment, and pickup-location patterns using filters and visualizations.



## Task Progression



- **Task 1:** Data Cleaning and Quality Assessment

- **Task 2:** SQL Exploratory Data Analysis

- **Task 3:** Interactive Power BI Dashboard
